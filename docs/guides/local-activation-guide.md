# التفعيل المحلي (بدون سيرفر خارجي)

هذا النظام يطلب كود تفعيل أول تشغيل، ويربطه بالجهاز محلياً.

## عند الزبون

1. شغّل التطبيق.
2. ستظهر شاشة التفعيل وفيها `Machine code`.
3. أرسل هذا الرمز لك (12 حرف).

## عندك أنت (توليد كود)

من جذر المشروع:

```bash
powershell -ExecutionPolicy Bypass -File scripts/generate-activation-code.ps1 ABCDEF123456
```

أو:

```bash
npm run license:generate -- ABCDEF123456
```

سينتج كود بالشكل:

`DEKEN-ABCDEF123456-XXXXXX`

## إدخال الكود

1. الزبون يدخل الكود في شاشة التفعيل.
2. إذا صحيح، النسخة تُفتح وتُحفظ حالة التفعيل على نفس الجهاز.

## ملاحظات

- التفعيل مرتبط ببصمة الجهاز، لذلك نقل نفس الحزمة لجهاز آخر يحتاج كود جديد.
- الحل محلي بالكامل (بدون أي API خارجي).
