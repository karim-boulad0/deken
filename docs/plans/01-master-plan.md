# الخطة الرئيسية — تطبيق Deken للمحلات التجارية ومتاجر التجزئة

**الإصدار:** 1.3  
**التاريخ:** 2026-04-25  
**سجل مختصر:** 1.1 — ثنائية اللغة + i18n. 1.2 — مبدأ الترحيلات (migrations) الواضحة والمنطقية. 1.3 — خطة توسعة: [موردون، مصاريف، حركة الصندوق](./05-suppliers-expenses-cashflow.md).

## ملخص

تطبيق سطح مكتب أوفلاين للمحلات التجارية ومتاجر التجزئة: بيع سريع (POS)، جرد، ديون، وتقارير — بدون تعقيد تنصيب سيرفرات أو قواعد بيانات عند الزبون.

---

## الهدف الأساسي (The Core Goal)

بناء تطبيق ديسكتوب **أوفلاين وذاتي الاكتمال (Self-Contained)** للمحلات التجارية ومتاجر التجزئة، يركز على:

- **السرعة القصوى** في عمليات البيع (POS).
- **إدارة الديون الرقمية** مدمجة مع البيع.
- **سهولة التنصيب** دون الحاجة لتعريف سيرفرات أو قواعد بيانات معقدة عند الزبون.

---

## الاستراتيجية التقنية (The Technical Strategy)

### التقنيات (Stack)

| الطبقة           | الاختيار        | السبب                                                                 |
| ---------------- | --------------- | --------------------------------------------------------------------- |
| تطبيق سطح المكتب | **Electron.js** | تغليف ويب كتطبيق ديسكتوب، توزيع موحّد، وصول للطباعة والملفات.         |
| واجهة المستخدم   | **React**       | منظومة مكوّنات، أداء جيد، توظيف واسع.                                 |
| قاعدة البيانات   | **SQLite**      | ملف واحد داخل مجلد البرنامج، أوفلاين 100%، بدون MySQL أو تنصيب منفصل. |

### ترحيلات المخطط (Schema migrations)

- **مفهومة**: اسم الملف والترتيب يوضحان **ماذا** يتغيّر؛ تعليق قصير في أعلى كل ترحيل يشرح السبب عند الحاجة.
- **منطقية**: ترحيل واحد = **تغيير متماسك** (لا خلط “إصلاح باگ” مع “ميزة جديدة” في نفس الملف إن أمكن تجنّب ذلك).
- **قابلة للمراجعة**: SQL واضح، أسماء جداول/أعمدة متسقة، فهارس وقيود بقرار واضح — لتسهيل المراجعة والدعم لاحقاً عند الزبائن.

### تجربة المستخدم (UX)

- **ثنائية اللغة (Arabic + English)**: واجهة المستخدم تدعم العربية والإنجليزية بالكامل (قوائم، أزرار، رسائل، تقارير واجهة) عبر **تدويل (i18n)** — تبديل لغة من الإعدادات (أو حسب لغة النظام مع إمكانية التجاوز).
- **اتجاه الواجهة**: **RTL** عند اختيار العربية، **LTR** عند اختيار الإنجليزية؛ خطوط ومسافات مناسبة لكل اتجاه.
- دعم **ماسح الباركود** كمسار إدخال أساسي (تركيز، اختصارات، حقول مناسبة).
- **طباعة حرارية** (Silent Print) حيث يسمح النظام والسياسات الأمنية؛ قوالب الإيصال تتبع لغة الطباعة أو إعداد مستقل (يُحدَّد في مرحلة التصميم).

### المميزات الأساسية (حسب الأولوية للتخطيط)

1. **POS سريع**: تعدد عملات (ليرة / دولار)، سعر صرف لحظي قابل للتعديل.
2. **إدارة الديون**: “دفتر ديون رقمي” مرتبط بالعملاء وفواتير البيع.
3. **الجرد الذكي**: تنبيهات نقص كميات وتواريخ صلاحية (حيث ينطبق).
4. **تقارير بصرية**: لوحة معلومات (Dashboard) — مثلاً حركة مبيعات أسبوعية.

---

## القيمة المضافة (Value Proposition)

النظام **Portable**: نسخ احتياطي/نقل ملف قاعدة البيانات والإعدادات، تنصيب بسيط، **لا اعتماد على إنترنت أو سيرفرات** للتشغيل اليومي — مناسب للمحلات البسيطة وتقليل العبء على الدعم الفني.
