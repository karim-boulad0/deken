# خطط المنتج (`docs/plans/`)

هذا المجلد **مخصص فقط** لمستندات التخطيط طويلة المدى (رؤية، مراحل، تفصيل ميزات)، وليس لكود التطبيق.

## الفهرس

| الملف | الوصف |
|--------|--------|
| [01-master-plan.md](./01-master-plan.md) | الخطة الاستراتيجية الرئيسية (Stack، أهداف، مراحل) |
| [02-implementation-roadmap.md](./02-implementation-roadmap.md) | تسلسل التنفيذ: تسطيب → layout → تصميم وi18n → منطق وDB |
| [02-implementation-checklists.md](./02-implementation-checklists.md) | قوائم مهام Markdown لكل مراحل 02 (ضع `[x]` عند الإنجاز) |

## إضافة خطة جديدة

1. أنشئ ملفاً جديداً هنا فقط (لا في جذر المستودع).
2. التسمية: `NN-short-descriptive-name.md` (إنجليزي صغير مع شرطات)، حيث `NN` ترتيب مقترح أو تسلسل زمني.
3. حدّث **هذا** `README.md` بسطر في الجدول أعلاه.
4. إذا كانت الخطة مرجعية عامة، حدّث أيضاً [../README.md](../README.md).

## العلاقة ببقية `docs/`

- قرارات تقنية “لماذا اخترنا X”: تنتقل تدريجياً إلى `docs/architecture/` كـ ADR عند الحاجة.
- أدلة خطوة بخطوة: `docs/guides/`.
